## 📝 Documentation Standards

### File Naming
- Use UPPERCASE for main files (e.g., `README.md`, `OVERVIEW.md`)
- Use numbered prefixes for sequential docs (e.g., `00_`, `01_`)
- Use descriptive names (e.g., `REGISTRATION_FLOW.md`)

### Structure
- Each major system has its own folder
- Each folder has a README or index file
- Sequential guides are numbered
- Reference docs are clearly named

### Status Indicators
- ✅ Complete and tested
- 🚧 In progress
- ⏳ Planned
- 📋 Documentation only
